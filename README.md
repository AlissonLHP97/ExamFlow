## Como executar o ExamFlow

Para executar o sistema não é necessário instalar Visual Studio, .NET, SQL Server ou SQL Server Management Studio.

### Pré-requisito

É necessário ter o **Docker Desktop** instalado e em execução na máquina.

### Executando o sistema

1. Clone ou baixe este repositório.

2. Abra um terminal na pasta raiz do projeto, onde está localizado o arquivo `docker-compose.yml`.

3. Execute:

   ```bash
   docker compose up --build -d
